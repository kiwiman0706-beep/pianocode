# 🎹 JazzSteps Lite

ジャズピアノのコード練習用Webアプリ（インストール不要・HTML1枚）。
ミニMIDIキーボードで**ホームポジションのまま最小の鍵盤数**で弾く練習をするためのツールです。

## 使い方

`index.html` をブラウザで開くだけ。
MIDIキーボードを使う場合は **Chrome / Edge**、かつ **HTTPS または localhost** で開いてください
（`file://` 直開きだとMIDIが使えないので、その場合は画面鍵盤／PCキーで練習できます）。

ローカルで手軽に試すなら:

```bash
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

GitHub Pages に置けばそのままHTTPSで公開でき、MIDIも動きます。

## できること（MVP）

- **コード進行を入力**（例 `Dm7 G7 Cmaj7`）してループ練習
- **ワンクリック移調**（±6半音）＋「最初のコードをCに」ボタン → **Cで練習**
- **ボイシング自動生成**
  - 左手＝ルート+5th（C3域に固定）
  - 右手＝3rd+7th+テンション（C4域に固定＝ホームポジション維持）
  - 例: `Cadd9` → 左 C3+G3 / 右 D4+E4
- **ゆるい判定（モード切替）**
  - **ゆるい**: ルート+3rd+7th が鳴れば正解（オクターブ違い・転回・テンション追加は自由）
  - **超ゆるい**: 3rd と 7th（コードの色）だけ合えばOK（ルート/5th省略可）
  - **厳格**: 構成音ぴったり
- **入力3種**: Web MIDI / 画面鍵盤クリック / PCキーボード
  - 右手 `A W S E D F T G Y H U J`（C4〜） / 左手 `Z X C V B N M`（C3〜白鍵）
- 内蔵ピアノ音（Web Audio）、お手本のハイライト表示・試聴

## 設計メモ

- **パーサ** `parseChord()`: 音名 + コア品質テーブル + 変化トークンの2段構成。
  三和音・6th・7th系・maj7・m7b5・dim7・aug・sus・add9・9/11/13・b9/#9/#11/b13 等に対応。
- **ボイシング** `voicing()`: 左=ルート+5th、右=それ以外の構成音をC4域のピッチクラスに畳む。
  各音のオクターブ位置を固定することで「ホームポジション維持」を実現。
- **判定** `judge()`: ピッチクラス集合で比較（オクターブ非依存）。モードで必須音を切替。
