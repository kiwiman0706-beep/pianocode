# 🎹 MiniPianoChord

ミニ鍵盤（例: Yamaha PSS-A50）でジャズ／ポップスのコード進行を練習するためのWebアプリ。
**ホームポジションのまま最小の鍵盤数**で弾けるようボイシングを自動生成します。HTML1枚＋αで動作し、PWAとしてインストールもできます。

## 使い方

`index.html` をブラウザで開くだけ。
MIDIキーボードを使う場合は **Chrome / Edge**、かつ **HTTPS または localhost** で開いてください
（`file://` 直開きだとMIDIが使えません。その場合は画面鍵盤／PCキーで練習できます）。

ローカルで試す:

```bash
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

GitHub Pages に置けばHTTPSで公開でき、MIDI・PWAインストール・オフライン起動が有効になります。

## できること

- **コード進行を入力**（例 `Dm7 G7 Cmaj7`）してループ練習。**ワンクリック移調**＋「最初のコードをCに」。
- **ボイシング3種を切替**
  - 覚えやすい: 左＝ルート+5th / 右＝3rd+7th+テンション
  - ジャズ定番（シェル）: 左＝ルート / 右＝3rd+7th（7th系は5th省略）
  - **運指最小**: 前のコードに一番近い転回を選び、手をほぼ動かさず指だけ最短移動（狭い音域にクランプ）
- **判定モード**: ゆるい（ルート+3rd+7th）／超ゆるい（3rd+7thだけ）／厳格（構成音ぴったり）。すべて音名（ピッチクラス）比較なのでオクターブ非依存＝ミニ鍵盤のオクターブシフトに強い。
- **5度圏（サークル・オブ・フィフス）**: 曲で使うコード／練習中のコードをハイライト。近いコードほど円周上で隣どうし。
- **コード譜の取り込み**
  - 貼り付け: 楽器.me などのコード譜をそのまま貼ると、歌詞・セクション名・小節線を無視してコードだけ抽出。
  - ブックマークレット: コピー禁止サイト（楽器.me）向け。ページのDOMを直接読み、アプリへ `#import=…` で受け渡し。
- **入力3種**: Web MIDI / 画面鍵盤クリック / PCキーボード。内蔵ピアノ音（Web Audio）、お手本ハイライト・試聴。
- **ローカル保存＋インポート/エクスポート**: 設定と「マイ曲」ライブラリを端末に保存。全データをJSONで書き出し／読み込み。
- **PWA**: マニフェスト＋Service Workerでインストール・オフライン対応。

## 構成

- `index.html` — アプリ本体（UI・パーサ・ボイシング・判定・5度圏・MIDI/音・保存）
- `manifest.webmanifest`, `sw.js`, `icon-*.png` — PWA用

## 設計メモ

- **パーサ** `parseChord()`: 音名 + コア品質テーブル + 変化トークンの2段構成。三和音・6th・7th系・maj7・m7b5・dim7・aug・sus・add9・9/11/13・b9/#9/#11/b13、日本語表記 `m7-5` 等に対応。
- **ボイシング**: `voicing()`（固定オクターブ）と `voicingMin()`（前後で最短になる連鎖ボイスリーディング）。
- **判定** `judge()`: ピッチクラス集合で比較（オクターブ非依存）。モードで必須音を切替。
